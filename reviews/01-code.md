# Critical Code Review

## Severity guide
S0 = security/data-loss risk; S1 = wrong/broken; S2 = bad smell, dead code, significant tech debt; S3 = nit/style

## Findings

### S0 — Critical

- **utils/fetch_ces_data.py:78** — `requests.post(API_URL, headers=HEADERS, data=json.dumps(payload))` has no `timeout`. A hung BLS connection blocks the calling thread forever and pins a gunicorn gthread worker (and via the data-refresh agent, the whole tab tree). **Fix:** add `timeout=30` to match `fetch_laus_data.py:79` / the other fetchers.
- **utils/embeddings.py:275** — `np.load(CACHE_EMBEDDINGS, allow_pickle=True)`. The cache lives under `HF_HOME`/`TRANSFORMERS_CACHE` (defaults to `~/.cache` if neither set). If that directory is ever attacker-writable (shared CI/dev host, misconfigured volume), arbitrary code executes at load. **Fix:** stop pickling object arrays — store `chunks` as `np.array(chunks, dtype='<U…')` or in a sidecar JSON, then load with `allow_pickle=False`.
- **app.py:23 + utils/{data_pipeline,fetch_ces_data,fetch_laus_data,fetch_population_data,merge_all_data}.py** — Six modules call `logging.basicConfig(...)` at import time. Library modules must not call basicConfig; whichever loads first wins and silently overrides any handler the application/test runner installed (an info-level format under `pytest --log-cli-level=ERROR` is the visible symptom). **Fix:** keep `logging.basicConfig` only in `app.py`; library modules just `logger = logging.getLogger(__name__)`.
- **utils/fetch_population_data.py:35,48** — Two bare `except:` blocks swallow `KeyboardInterrupt` and `SystemExit`. **Fix:** narrow to `except Exception:` and log the suppressed error so partial-fetch failures don't silently corrupt the population file.
- **deploy.sh:30,53** — `sudo apt-get install -y docker.io / docker-compose-plugin` without verification, on first failure to find docker. A user pasting this into a shared dev box gets root-level apt mutations without confirmation. **Fix:** print the planned command and require an explicit `--yes-install` flag, or document that the script assumes prior consent.

### S1 — Wrong/broken

- **utils/forecasting/selection.py:288-303** — `_baseline_residuals` has two branches that produce identical output: `if any(isinstance(c, NaiveForecaster) for c in candidates)` always falls through to a fresh `NaiveForecaster().fit(...)` either way. - **utils/agents/blurb_orchestra.py:218-220** — `if width > last_val * 0.5:` flags CI > 50% of last value but the message says `"95 % prediction interval is {width:.1f} ({width/last_val*100:.0f}% of the last observed value)"`. Comparing absolute width to a fraction of value works only when both are percent-scale; for `Unemployment` (persons, ~1.5M) the cutoff `last_val * 0.5 = 750000` is huge in absolute units — and for any sector employment (hundreds of thousands) the invariant rarely fires. **Fix:** compute width-as-fraction first, then compare: `if last_val > 0 and width / last_val > 0.5`.

- **utils/agents/sentence_rag.py:144-148** — In `ranking_sentences`, the per-state value accumulator mixes `list` and `float` representations of the same key (`if isinstance(existing, list): existing.append(val_f); table[...]=existing` else `table[...] = [existing, val_f]`). ## Top 10 highest-leverage fixes

1. **Add `timeout=` to `fetch_ces_data.py:78`.** Prevents a hung BLS connection from pinning a gunicorn worker indefinitely. Five-character fix.
2. **Stop using `np.load(allow_pickle=True)` on the embeddings cache.** Switch to storing chunks as JSON sidecar + numpy float matrix, load with `allow_pickle=False`. Removes a real arbitrary-code-execution sink.
3. **Drop pyspark / scikit-learn / tqdm / tenacity from `requirements.txt` and openjdk-21 from `Dockerfile.dashboard`.** ~500 MB image size reduction, plus removes a CVE surface.
4. **Wire the Phase E/F fetchers (QCEW, JOLTS, CPI, FRED, BEA) into `merge_all_data`.** Right now they fetch into `data/raw/{source}/` and the merger never reads them — every Phase E commit landed a dead-end.
5. **Fix `_apply_threshold` / `_recommendation_panel` to use `{"Region Mean", "Region Median"}` as the aggregate-row sentinel** (super_tab.py:164, 240, 245). Currently the recommendation panel ranks the aggregates as if they were states.
6. **Delete the dead-code/stale-import block:** `utils/agents/image_writer.py`, `utils/data_pipeline.py:validate_lfpr_data`, `utils/embeddings.py:preprocess_for_embedding`, `utils/model_utils.py`, `utils/graphics.py`, plus the dead imports in `tabs/about_tab.py`, `tabs/lfp_tab.py:43`, `utils/agents/blurb_async.py:35`, `utils/agents/blurb_orchestra.py:77`. ~250 LOC reduction.
7. **Update the stale smoke tests** (`tests/tabs/test_tab_smoke.py:71-94`) so they reflect the polling callbacks that were added.
8. **Replace duplicated FIPS dictionaries** (`utils/fetch_population_data.py:15`, `utils/merge_all_data.py:28`) with `ONTOLOGY.states_by_fips`. Removes a drift surface.
9. **Move `logging.basicConfig` calls out of every library module** (`utils/data_pipeline.py:17`, `utils/fetch_*.py`, `utils/merge_all_data.py:9`) so the application/test runner owns logging configuration.
10. **Extract a `utils.data_pipeline.load_panel_df()` helper** replacing the three near-identical implementations in `app.py:65`, `tabs/lfp_tab.py:101`, `tabs/super_tab.py:62`.

- **Ontology-driven design.** `utils/ontology.py` is the single source of truth for states, supersectors, measures, and series-id decoding. Excellent abstraction — every downstream consumer (fetchers, RAG sentences, agent tools) goes through it. Preserve this pattern when wiring the new Phase E/F sources.
